# Autonomous Line Follower Robot using PD Control

An Arduino-based autonomous line follower robot built using QTR-8RC reflectance sensors and PD control logic for stable and high-speed line tracking.

## Features
- PD control based steering
- QTR-8RC sensor array
- Stable line tracking
- Motor speed correction
- Sensor calibration
- Arduino Mega 2560 support

## Hardware Used
- Arduino Mega 2560
- QTR-8RC Sensor Array
- TB6612FNG Motor Driver
- DC Motors
- Li-ion Battery Pack

## Technologies
- Arduino
- Embedded Systems
- Robotics
- Control Systems
- Sensor Calibration

## Included Files
- PD_Control_LFR.ino
- QTR8RC_Mega_Controller.ino
- LFR Algorithm PDF
